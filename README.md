# Spotify MenuBar

맥 메뉴바에서 지금 나오는 Spotify 곡을 보여주는 앱입니다.

![재생 화면](docs/images/player.png)

## 왜 만들었나요

Spotify 데스크톱 앱에는 메뉴바 기능이 없습니다. 무슨 곡이 나오고 있는지 보려면 그때마다 Spotify 창을 앞으로 꺼내야 하는데, 다른 일을 하다 곡이 궁금해질 때마다 창을 뒤적이는 게 번거로웠습니다. 메뉴바에 `노래 - 가수` 한 줄만 있으면 될 일이었습니다.

## 이런 걸 합니다

재생 중인 곡이 메뉴바에 `노래 - 가수`로 뜹니다. 일시정지 중에는 글자가 흐려져서 멈춰 있다는 걸 알 수 있습니다. 제목이 길면 40자에서 자르는데, 이 길이는 설정에서 바꿀 수 있습니다.

메뉴바 글자를 클릭하면 위 화면이 열립니다. 이전 곡과 다음 곡, 재생과 일시정지가 있고, 제목을 누르면 그 곡이 Spotify에서 열립니다.

커버 테두리를 도는 링이 진행 상태입니다. 링을 끌면 원하는 지점으로 이동하고, 마우스를 올리면 지금 위치와 곡 길이가 커버 위에 뜹니다.

![링에 마우스를 올린 모습](docs/images/player-hover.png)

배경에는 앨범 커버에서 가장 선명한 색을 뽑아 옅게 깝니다. 곡이 바뀌면 화면 색도 따라 바뀝니다. 창 폭은 제목 길이에 맞춰 늘었다 줄어서, 짧은 곡에서 오른쪽이 휑하게 남지 않습니다.

![짧은 제목일 때](docs/images/player-short.png)

메뉴바 글자를 오른쪽 클릭하면 설정이 나옵니다. Spotify 열기, 메뉴바에 표시할 글자 수(20 / 30 / 40 / 60자), 로그인 시 자동 실행, 종료가 있습니다.

## 설치

macOS 13 이상과 Spotify 데스크톱 앱이 필요합니다.

### 내려받아 설치하기

[릴리스 페이지](https://github.com/OseungKwon/spotify-menubar/releases/latest)에서 `.dmg`를 받아 앱을 `Applications`로 끌어다 놓습니다.

처음 열면 **"확인할 수 없는 개발자"** 경고가 뜹니다. 개발자 인증서 없이 배포해서 생기는 절차입니다.
**시스템 설정 → 개인정보 보호 및 보안**을 열면 아래쪽에 차단 안내가 있습니다. 거기서 **확인 없이 열기**를 눌러 주세요. 한 번만 거치면 다음부터는 바로 열립니다.

### 소스에서 빌드하기

[Xcode Command Line Tools](https://developer.apple.com/download/all/)가 필요합니다. 터미널에서 아래를 실행해 주세요.

```bash
git clone https://github.com/OseungKwon/spotify-menubar.git
cd spotify-menubar
make install
```

앱이 만들어져 `응용 프로그램`에 설치되고 바로 실행됩니다. 이렇게 직접 빌드한 앱에는 위의 경고가 뜨지 않습니다.

### 처음 실행할 때

어느 쪽으로 설치하셨든 **"SpotifyMenuBar에서 Spotify을(를) 제어하도록 허용하시겠습니까?"** 창이 뜹니다.
허용해야 곡 정보를 읽어올 수 있습니다. 실수로 거부하셨다면 메뉴바에 `권한 필요`가 뜨는데, 그 글자를 누르면 시스템 설정으로 갈 수 있습니다.

## 알아두기

- **Spotify 데스크톱 앱에서 재생 중일 때만** 동작합니다. 웹 플레이어나 휴대폰에서 듣는 곡은 읽어오지 못하니, 아무것도 뜨지 않는다면 이쪽을 확인해 보세요
- 좋아요, 가사, 재생 목록은 지원하지 않습니다
- 앱을 다시 빌드하면 권한을 한 번 더 물어볼 수 있습니다

## 만들 때 쓰는 명령어

```bash
make build     # 앱만 만들기
make run       # 만들고 실행
make install   # 응용 프로그램에 설치하고 실행
make dmg       # 배포용 dmg 만들기
make clean
```
